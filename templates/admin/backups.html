What a restore changes

The snapshot can return Denmart to its previous catalogue, pricing, inventory, orders, sales, staff accounts, settings and Daraja configuration. Keep the backup file somewhere secure because it contains operational and authentication data.

Fresh-install recoveryOn a new Denmart deployment, create/open the database, open Backups, upload the saved JSON or SQLite file, confirm RESTORE, then sign in again. The current schema is created before import, so recovery also works on an empty fresh database.
